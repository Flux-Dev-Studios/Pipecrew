# PipeCrew Plumbing Services

A responsive landing page for PipeCrew, a plumbing services business serving Lagos and nearby areas. The site is built with TypeScript and Vite.

## Run locally

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

## Business details before launch

Update the `business` object in `src/main.ts` with PipeCrew's verified phone number and WhatsApp number. The quote form opens a WhatsApp message when a WhatsApp number is configured. Until then, the form explains that the request cannot be sent directly. Confirm service coverage and replace the sample photography with approved business images before publishing.
